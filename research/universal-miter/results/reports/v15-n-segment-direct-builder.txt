ARCHITECTURE

  build_direct_chain(kernel, side_surfaces[N], boundaries[N-1],
                     path_start, start_tangent, path_end, end_tangent, K)
  - accepts solved surfaces and joint boundaries only; no boundary strategy
    knowledge
  - N=1 delegates to build_direct_single
  - build_direct_joint is the N=2 wrapper around build_direct_chain

TOPOLOGY (N pieces, K profile segments)

  faces    = N*K + 2
  edges    = (2*N + 1)*K
  vertices = (N + 1)*K
  each edge has 4 edge-uses; V - E + F = 2 per shell
  one shared vertex set and one shared edge set per joint; no duplicate joint
  faces.

FINDINGS

  1. The cap profile loop closes at v_max, not at the first seam V=0. Using
     V=0 for the closing edge produced loop gaps at profile boundary K-1 -> 0.
  2. Each intermediate surface is checked for the same profile V at both
     adjacent joints; a mismatch is a typed refusal.
  3. Joint vertices/edges are created once and shared by both adjacent side
     faces.
  4. The builder is strategy-independent; the 2-segment exact and hybrid tests
     reach it through the wrapper.
